# TB Care frontend

React + Vite + Tailwind CSS web app. See the [main README](../README.md) for the full project description.

```bash
npm install
npm run dev        # opens http://localhost:5173
```

The app calls the backend at `http://127.0.0.1:8000` by default. To use a different address, copy `.env.example` to `.env` and edit `VITE_API_URL`.

Pages: Home, Upload, Results, Learn.
